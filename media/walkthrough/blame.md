# Blame on the current line

Click any line in a file git tracks. After a quarter of a second its last change appears at the end of
the line, in faded text:

```
const token = await refresh(session);      You, 3 days ago • Fix token refresh (#412)
```

Hover the faded text for the full commit, a diff of the change, the line's recent history, and links
to **Time travel** and **Show in graph**. Select several lines for a summary of who wrote them.
